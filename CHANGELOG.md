# Histórico de mudanças

## 1.3.0 — 2026-10-04

- Incorporar referências metodológicas do ECC 2.2.3 a 17 skills em 14 plugins, com carregamento sob demanda e créditos MIT.
- Preservar as skills adicionais e as versões mais recentes existentes no repositório.
- Adicionar LinkedIn Post Design Kit e LinkedIn Design Studio com seus recursos e cinco skills ao catálogo de criação.
- Reforçar critérios de evidência, revisão editorial, legibilidade, avaliação educacional e prevenção de dupla contagem de tokens.
- Manter scripts e integrações existentes; as adaptações são instruções e não ativam hooks ou serviços externos.

## 1.2.0 — 2026-10-03

- Organizar os 28 plugins em oito áreas com atalhos no README e catálogo das 94 skills.
- Adicionar guia rápido, índice da documentação e instruções de contribuição.
- Gerar README, catálogo e índice a partir de manifestos, skills e metadados de áreas, preservando caminhos e identificadores existentes.
- Adicionar conferência de links locais, testes da navegação e workflow de validação em push e pull request.

## 1.1.0 — 2026-10-03

- Adicionar DataLab, SQL Mentor, Python Lab, Dashboard Studio, Pesquisa Científica, Artigo Crítico, Anki Builder, Carreira Lab, Documento Studio, GitHub Organizer, Skill Auditor, Plugin Builder e API Explorer.
- Ampliar Edital Fácil e Residência Radar Brasil com quatro skills especializadas cada.
- Incluir a versão existente do VisualExplain e adicionar suas skills de linha do tempo, processos animados e quiz.
- Adicionar skills a PostLab, MedQuest, Dados de Saúde Brasil, InvestIA e Comparador de Carros sem remover suas instruções anteriores.
- Acrescentar 79 skills com entradas, fluxo, entrega, limites e exemplo; incluir metadados de interface.
- Atualizar índice e documentação para listar todas as skills, preservando o campo legado `skill`.
- Corrigir subtítulos de cinco plugins existentes para respeitar o limite de 30 caracteres, sincronizando suas versões nos overlays.
- Adicionar exportação TSV para Anki, validador local de catálogo e empacotador de plugin com testes.

Esta versão é uma ampliação do código-fonte. Não modifica instalações dos plugins nas contas dos usuários.
