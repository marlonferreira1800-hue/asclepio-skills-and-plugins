# Skill Auditor

Avaliar estrutura, instruções, recursos e comportamento de skills com casos de uso.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`auditar-skill`](skills/auditar-skill/SKILL.md) | Auditar instruções de skill |
| [`validar-estrutura-skill`](skills/validar-estrutura-skill/SKILL.md) | Validar estrutura de skill |
| [`avaliar-exemplos-skill`](skills/avaliar-exemplos-skill/SKILL.md) | Avaliar exemplos de skill |
| [`revisar-limites-skill`](skills/revisar-limites-skill/SKILL.md) | Revisar limites de skill |

## Requisitos e execução

Arquivos de skills; Python/PyYAML para validação estrutural. Avaliação comportamental exige executar tarefas de exemplo.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Audite esta skill e corrija instruções ambíguas.
- Valide esta pasta de skill antes de empacotar.
- Teste esta skill com um caso comum e dois casos difíceis.
- Revise esta skill que acessa APIs e grava relatórios.
