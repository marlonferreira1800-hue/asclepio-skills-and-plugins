# LinkedIn Conteúdo Diário

Plugin privado de produtividade que empacota a skill
`linkedin-conteudo-diario` e seus arquivos de apoio.

O plugin prepara lotes de cinco posts educativos com imagens, organiza os
horários de Brasília, valida os arquivos e solicita aprovação antes do
agendamento no LinkedIn.

Ele não inclui credenciais, não usa uma API não oficial do LinkedIn e não
publica sem confirmação explícita do lote atual.
