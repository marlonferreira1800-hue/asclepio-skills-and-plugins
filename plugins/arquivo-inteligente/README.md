# Arquivo Inteligente

Inventariar arquivos, reconhecer duplicatas, propor nomes e organizar pastas com rastreabilidade.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`classificar-arquivos`](skills/classificar-arquivos/SKILL.md) | Classificar arquivos |
| [`detectar-arquivos-duplicados`](skills/detectar-arquivos-duplicados/SKILL.md) | Detectar arquivos duplicados |
| [`padronizar-nomes-arquivos`](skills/padronizar-nomes-arquivos/SKILL.md) | Padronizar nomes de arquivos |
| [`planejar-pastas`](skills/planejar-pastas/SKILL.md) | Planejar estrutura de pastas |

## Requisitos e execução

Acesso autorizado aos arquivos; Python padrão para inventário. Mudanças usam plano explícito, sem exclusão automática.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Organize um inventário das minhas apostilas por disciplina.
- Encontre arquivos repetidos nesta pasta sem excluir nenhum.
- Padronize os nomes das apostilas e mostre o mapa de alteração.
- Planeje pastas para aulas, provas, resumos e artigos.
