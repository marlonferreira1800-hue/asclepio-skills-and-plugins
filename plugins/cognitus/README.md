# Cognitus

Plugin privado de tutoria para aprendizagem ativa. O Cognitus conduz sessões
de estudo por diagnóstico, método socrático, técnica de Feynman, prática
deliberada e repetição espaçada.

## Habilidade incluída

- `aprendizagem-ativa`: calibra a sessão, orienta o raciocínio sem antecipar
  conclusões, usa diagramas Mermaid quando úteis e produz flashcards Anki
  depois que o estudante demonstra compreensão.
