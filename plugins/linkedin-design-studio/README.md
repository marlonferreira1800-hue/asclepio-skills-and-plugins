# LinkedIn Design Studio

Plugin privado com quatro skills para planejar conteúdo visual de LinkedIn:

- **LinkedIn Design Router** escolhe o fluxo adequado.
- **Penpot LinkedIn Design** estrutura peças profissionais e consistentes.
- **Excalidraw LinkedIn Infographic** transforma explicações em diagramas desenhados à mão.
- **tldraw LinkedIn Canvas** organiza ideias, fluxos e storyboards em uma tela visual.

## Como usar

Peça um post, carrossel, infográfico ou storyboard e informe o tema, público e objetivo. Se algum dado estiver faltando, as skills usam uma opção padrão razoável e deixam a suposição explícita. Podem entregar conceito visual, texto, roteiro slide a slide, especificação de layout e prompts ou código de apoio quando solicitado.
