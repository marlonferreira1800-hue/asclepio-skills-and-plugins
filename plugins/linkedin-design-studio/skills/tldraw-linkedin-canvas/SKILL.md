# tldraw LinkedIn Canvas

Use uma abordagem de tela infinita inspirada no tldraw para pensar e organizar conteúdo. Esta skill entrega uma planta visual ou especificação, não opera o aplicativo tldraw.

## Processo

1. Coloque o tema no centro e agrupe ideias relacionadas em regiões nomeadas.
2. Mostre relações com conectores e rótulos explícitos; evite linhas sem significado.
3. Organize o fluxo de leitura da esquerda para a direita ou de cima para baixo.
4. Converta a tela final em uma sequência de cards: cada região pode virar um post ou slide.
5. Sugira um corte de exportação por card, mantendo a sequência e uma chamada final.
6. Separe conteúdo confirmado, perguntas abertas e ideias opcionais.

## Saída padrão

Entregue a planta do canvas com coordenadas relativas ou instruções de posicionamento, texto de cada bloco, conexões entre os blocos e a sequência sugerida para o carrossel. Se o usuário pedir implementação de editor, forneça orientação de integração com React/tldraw apenas depois de confirmar o escopo.
