# Ensaios Clínicos Radar

Buscar ensaios registrados, comparar protocolos e organizar fases e status com fontes.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`buscar-ensaios-registrados`](skills/buscar-ensaios-registrados/SKILL.md) | Buscar ensaios registrados |
| [`comparar-protocolos-ensaios`](skills/comparar-protocolos-ensaios/SKILL.md) | Comparar protocolos de ensaios |
| [`organizar-fases-ensaios`](skills/organizar-fases-ensaios/SKILL.md) | Organizar fases de ensaios |
| [`verificar-status-ensaios`](skills/verificar-status-ensaios/SKILL.md) | Verificar status de ensaios |

## Requisitos e execução

Pesquisa em registros oficiais como ClinicalTrials.gov ou ReBEC; não decide elegibilidade individual.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Encontre ensaios registrados sobre prevenção de dengue.
- Compare os protocolos destes três ensaios.
- Organize estes estudos por fase e explique as diferenças.
- Confira quais destes estudos estão recrutando no Brasil.
