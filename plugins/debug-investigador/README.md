# Debug Investigador

Reproduzir falhas, investigar causas, aplicar correções e verificar resultados em projetos diversos.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`reproduzir-falha`](skills/reproduzir-falha/SKILL.md) | Reproduzir falha |
| [`investigar-causa-falha`](skills/investigar-causa-falha/SKILL.md) | Investigar causa de falha |
| [`corrigir-causa-falha`](skills/corrigir-causa-falha/SKILL.md) | Corrigir causa de falha |
| [`verificar-correcao-falha`](skills/verificar-correcao-falha/SKILL.md) | Verificar correção de falha |

## Requisitos e execução

Checkout e ambiente de teste autorizados; logs sanitizados e ferramentas apropriadas à linguagem.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Reproduza este erro no menor exemplo possível.
- Investigue por que esta falha ocorre só em algumas entradas.
- Corrija a causa desta falha com a menor alteração necessária.
- Verifique se esta correção resolveu o erro sem quebrar os casos próximos.
