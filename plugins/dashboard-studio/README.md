## Requisitos e execução

Esquema e regras de negócio; navegadores web modernos para renderizar dashboards HTML autossuficientes com Chart.js; ambiente Python (Matplotlib, Seaborn, Plotly) para figuras de dados; Power BI para validar DAX e produzir arquivos PBIX. Sem ferramentas externas, entregar especificação e código completo.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Defina indicadores para um dashboard de vendas.
- Planeje um modelo estrela para pedidos, clientes e produtos.
- Crie medidas de receita, margem e crescimento anual no Power BI.
- Planeje três páginas de um dashboard comercial.
- Construa um dashboard interativo autossuficiente em HTML com Chart.js e filtros dinâmicos.
- Crie uma visualização profissional de tendências e rankings em Python com paleta acessível.
