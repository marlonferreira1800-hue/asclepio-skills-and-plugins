# Claude Motion

Toolkit completo de Motion Design para agentes de IA: regras de timing e curvas Bézier, física de molas, áudio procedural, simulações web 60fps e loops de revisão frame a frame.

## Skills desta ampliação

| Skill                                              | Função                                                   |
| -------------------------------------------------- | -------------------------------------------------------- |
| [`motion-design`](skills/motion-design/SKILL.md)   | Regras e física de animação, timing e curvas Bézier      |
| [`review-loop`](skills/review-loop/SKILL.md)       | Loop de auto-revisão visual com contact sheets           |
| [`sound-design`](skills/sound-design/SKILL.md)     | Design de som procedural sincronizado com motion graphics|
| [`web-sims`](skills/web-sims/SKILL.md)             | Simulações em canvas/tridimensionais capturadas em 60fps  |

## Requisitos e execução

Requer ambiente Node.js / Python para scripts auxiliares de áudio e captura, navegadores modernos para renderização de telas e bibliotecas de animação (Remotion, Motion / Framer Motion, Three.js).

Este pacote fornece instruções e diretrizes reutilizáveis para que agentes de IA apliquem bom gosto estético, consistência de movimento e polimento visual em interfaces e produções audiovisuais orientadas a código.

## Exemplos

- Aplique as regras de `motion-design` para suavizar transições e entradas de componentes.
- Crie um loop de revisão visual com contact sheets antes de aprovar uma animação.
- Sincronize efeitos sonoros procedurais com os pontos da timeline visual via `sound-design`.
- Estruture uma simulação de partículas ou 3D em HTML puro capturável em 60fps via `web-sims`.
