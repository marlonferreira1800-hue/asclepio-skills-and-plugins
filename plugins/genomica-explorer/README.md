# Genômica Explorer

Consultar genes, reconciliar identificadores, comparar anotações e mapear vias para pesquisa.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`consultar-genes`](skills/consultar-genes/SKILL.md) | Consultar genes |
| [`reconciliar-identificadores-genomicos`](skills/reconciliar-identificadores-genomicos/SKILL.md) | Reconciliar identificadores genômicos |
| [`comparar-anotacoes-genomicas`](skills/comparar-anotacoes-genomicas/SKILL.md) | Comparar anotações genômicas |
| [`mapear-vias-biologicas`](skills/mapear-vias-biologicas/SKILL.md) | Mapear vias biológicas |

## Requisitos e execução

Bases oficiais e acesso de consulta; dados autorizados. Não interpreta teste genético individual nem orienta conduta clínica.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Explique este gene e mostre as fontes oficiais.
- Converta estes IDs Ensembl para símbolos de genes humanos.
- Compare as anotações deste gene nas duas bases.
- Mapeie estes genes a vias biológicas e explique o que isso permite concluir.
