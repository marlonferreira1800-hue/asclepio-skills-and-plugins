# Artigo Crítico

Avaliar desenho, vieses, estatísticas e aplicabilidade de pesquisas.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`identificar-desenho-estudo`](skills/identificar-desenho-estudo/SKILL.md) | Identificar desenho do estudo |
| [`avaliar-vieses`](skills/avaliar-vieses/SKILL.md) | Avaliar vieses de artigo |
| [`interpretar-estatistica-artigo`](skills/interpretar-estatistica-artigo/SKILL.md) | Interpretar estatísticas de artigo |
| [`avaliar-aplicabilidade`](skills/avaliar-aplicabilidade/SKILL.md) | Avaliar aplicabilidade de estudo |

## Requisitos e execução

Texto do artigo e referências metodológicas oficiais ou primárias quando necessário.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Qual é o desenho deste estudo e o que ele permite concluir?
- Avalie o risco de viés deste ensaio clínico.
- Explique o risco relativo e o intervalo de confiança deste artigo.
- Este resultado se aplica à atenção primária brasileira?
