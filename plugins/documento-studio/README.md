# Documento Studio

Criar relatórios, formatar documentos, preparar apresentações e revisar PDFs.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`criar-relatorio-documento`](skills/criar-relatorio-documento/SKILL.md) | Criar relatório profissional |
| [`formatar-documento`](skills/formatar-documento/SKILL.md) | Formatar documento |
| [`montar-apresentacao`](skills/montar-apresentacao/SKILL.md) | Montar apresentação |
| [`revisar-pdf`](skills/revisar-pdf/SKILL.md) | Revisar PDF |

## Requisitos e execução

Ferramentas de DOCX/PPTX/PDF e renderizador para arquivo final; sem ferramentas entregar texto/roteiro.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Crie um relatório executivo com estes resultados.
- Formate este relatório com títulos, sumário e tabelas consistentes.
- Transforme este capítulo em uma apresentação de 15 minutos.
- Revise este PDF e aponte erros de texto e diagramação.
