# Newsletter Studio

Suíte multiagente para redação, curadoria, orquestração e publicação de newsletters.

## Skills Inclusas

- `newsletter-orchestrator`: Agente gerente que coordena a produção ponta-a-ponta de uma newsletter, desde a pesquisa das pautas até a redação e publicação final.
- `newsletter-curator`: Agente especializado na curadoria de pautas, notícias e tópicos de alto impacto e relevância técnica.
- `newsletter-copywriter`: Agente redator com estilo editorial refinado, alta densidade de sinal e heurísticas anti-IA.
- `newsletter-publisher`: Agente de entrega e publicação automática de edições prontas.
