# Bioestatística Lab

Escolher testes, avaliar pressupostos, calcular efeitos e interpretar resultados de pesquisa.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`escolher-teste-estatistico`](skills/escolher-teste-estatistico/SKILL.md) | Escolher teste estatístico |
| [`avaliar-pressupostos-estatisticos`](skills/avaliar-pressupostos-estatisticos/SKILL.md) | Avaliar pressupostos estatísticos |
| [`calcular-efeitos-estatisticos`](skills/calcular-efeitos-estatisticos/SKILL.md) | Calcular efeitos estatísticos |
| [`interpretar-resultados-pesquisa`](skills/interpretar-resultados-pesquisa/SKILL.md) | Interpretar resultados de pesquisa |

## Requisitos e execução

Dados agregados ou anonimizados e runtime estatístico quando houver execução; métodos verificados em fontes primárias.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Qual teste usar para medir alunos antes e depois de uma intervenção?
- Confira os pressupostos desta comparação de grupos.
- Calcule diferença de médias e intervalo de confiança destes grupos.
- Explique os resultados desta pesquisa em linguagem simples.
