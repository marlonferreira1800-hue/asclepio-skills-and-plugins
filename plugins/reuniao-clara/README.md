# Reunião Clara

Resumir transcrições, separar decisões, responsáveis e pendências.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`resumir-reuniao`](skills/resumir-reuniao/SKILL.md) | Resumir reunião |
| [`extrair-decisoes-reuniao`](skills/extrair-decisoes-reuniao/SKILL.md) | Extrair decisões de reunião |
| [`identificar-responsaveis-reuniao`](skills/identificar-responsaveis-reuniao/SKILL.md) | Identificar responsáveis de reunião |
| [`organizar-pendencias-reuniao`](skills/organizar-pendencias-reuniao/SKILL.md) | Organizar pendências de reunião |

## Requisitos e execução

Transcrição autorizada ou ferramenta de transcrição disponível. Não grava nem envia mensagens automaticamente.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Resuma esta reunião e destaque os assuntos principais.
- Liste somente as decisões tomadas nesta reunião.
- Extraia tarefas e responsáveis desta transcrição.
- Monte as pendências para a próxima reunião.
