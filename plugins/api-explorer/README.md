# API Explorer

Ler documentação, realizar consultas autorizadas, paginar resultados e documentar respostas.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`ler-documentacao-api`](skills/ler-documentacao-api/SKILL.md) | Ler documentação de API |
| [`testar-consulta-api`](skills/testar-consulta-api/SKILL.md) | Testar consulta de API |
| [`paginar-api`](skills/paginar-api/SKILL.md) | Paginar consulta de API |
| [`documentar-resposta-api`](skills/documentar-resposta-api/SKILL.md) | Documentar resposta de API |

## Requisitos e execução

Documentação oficial e ferramenta HTTP autorizada; credenciais somente via ambiente/armazenamento seguro.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Explique como consultar dados nesta API oficial.
- Teste este endpoint e mostre uma resposta sem expor credenciais.
- Colete até 10 páginas desta API e indique se o resultado está completo.
- Documente os campos desta resposta JSON de uma API.
