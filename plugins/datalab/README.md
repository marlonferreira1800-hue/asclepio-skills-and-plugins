# DataLab — Análise de Dados

Limpar bases, explorar dados, construir gráficos e produzir relatórios reproduzíveis.

## Skills desta ampliação

| Skill                                                            | Função                   |
| ---------------------------------------------------------------- | ------------------------ |
| [`limpar-base-dados`](skills/limpar-base-dados/SKILL.md)         | Limpar base de dados     |
| [`explorar-dados`](skills/explorar-dados/SKILL.md)               | Explorar dados           |
| [`criar-graficos-dados`](skills/criar-graficos-dados/SKILL.md)   | Criar gráficos de dados  |
| [`relatar-analise-dados`](skills/relatar-analise-dados/SKILL.md) | Relatar análise de dados |

## Requisitos e execução

Python; pandas/openpyxl para Excel; matplotlib ou equivalente para gráficos. Sem essas ferramentas, entregar plano e código sem alegar execução.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Limpe esta planilha de vendas e preserve os códigos de clientes.
- Explore esta base e identifique os fatores associados ao faturamento.
- Faça um gráfico mensal de receita com os dados desta tabela.
- Transforme esta análise em um relatório executivo com gráficos.
