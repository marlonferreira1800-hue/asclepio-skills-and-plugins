# Release Manager

Verificar versões, preparar releases, planejar migração e reversão.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`verificar-versao-release`](skills/verificar-versao-release/SKILL.md) | Verificar versão de release |
| [`preparar-entrega-release`](skills/preparar-entrega-release/SKILL.md) | Preparar entrega de release |
| [`planejar-migracao-release`](skills/planejar-migracao-release/SKILL.md) | Planejar migração de release |
| [`planejar-reversao-release`](skills/planejar-reversao-release/SKILL.md) | Planejar reversão de release |

## Requisitos e execução

Repositório e convenções do projeto; publicação e deploy só no escopo explicitamente autorizado.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Confira se a versão está correta para estas mudanças.
- Prepare a entrega desta versão com notas e hashes.
- Planeje a migração para esta nova versão sem perder dados.
- Prepare um plano de reversão para esta entrega.
