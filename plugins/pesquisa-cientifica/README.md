# Pesquisa Científica

Buscar literatura, extrair evidências, comparar estudos e organizar referências.

## Skills desta ampliação

| Skill                                                            | Função                       |
| ---------------------------------------------------------------- | ---------------------------- |
| [`buscar-literatura`](skills/buscar-literatura/SKILL.md)         | Buscar literatura científica |
| [`extrair-evidencias`](skills/extrair-evidencias/SKILL.md)       | Extrair evidências de artigo |
| [`comparar-estudos`](skills/comparar-estudos/SKILL.md)           | Comparar estudos científicos |
| [`organizar-referencias`](skills/organizar-referencias/SKILL.md) | Organizar referências        |

## Requisitos e execução

Pesquisa web e acesso aos textos; para arquivos, extração de PDF/OCR. Não inclui assinatura de periódicos.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Busque estudos sobre ensino de anatomia com realidade virtual.
- Extraia métodos e resultados deste artigo em uma tabela.
- Compare estes três artigos sobre um mesmo tratamento.
- Organize estas referências e gere um arquivo BibTeX.
