# Projeto do Zero

Refinar requisitos, definir aceite, dividir implementação e organizar dependências de um projeto.

## Skills desta ampliação

| Skill | Função |
|---|---|
| [`refinar-requisitos-projeto`](skills/refinar-requisitos-projeto/SKILL.md) | Refinar requisitos de projeto |
| [`definir-aceite-projeto`](skills/definir-aceite-projeto/SKILL.md) | Definir critérios de aceite |
| [`dividir-implementacao-projeto`](skills/dividir-implementacao-projeto/SKILL.md) | Dividir implementação de projeto |
| [`mapear-dependencias-projeto`](skills/mapear-dependencias-projeto/SKILL.md) | Mapear dependências de projeto |

## Requisitos e execução

Descrição da ideia, usuários e restrições; não requer integração nova.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Transforme minha ideia de aplicativo em requisitos claros.
- Crie critérios de aceite para estas funcionalidades.
- Divida este projeto em tarefas pequenas e executáveis.
- Mostre quais tarefas deste projeto dependem umas das outras.
