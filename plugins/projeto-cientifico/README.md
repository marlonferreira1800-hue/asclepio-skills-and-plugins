# Projeto Científico

Formular hipóteses, definir variáveis, planejar amostra e estruturar protocolos de pesquisa.

## Skills desta ampliação

| Skill | Função |

| [`formular-hipotese-pesquisa`](skills/formular-hipotese-pesquisa/SKILL.md) | Formular hipótese de pesquisa |
| [`definir-variaveis-pesquisa`](skills/definir-variaveis-pesquisa/SKILL.md) | Definir variáveis de pesquisa |
| [`planejar-amostra-pesquisa`](skills/planejar-amostra-pesquisa/SKILL.md) | Planejar amostra de pesquisa |

## Requisitos e execução

Pergunta e contexto científico; fontes metodológicas primárias e orientação institucional quando aplicável.

Este pacote fornece instruções reutilizáveis. Não cria conexões, assinaturas, publicação ou execução automática. Os scripts incluídos estão documentados nas skills que os utilizam.

## Exemplos

- Transforme ensino de anatomia com realidade virtual em uma pergunta de pesquisa.
- Defina variáveis para comparar dois métodos de estudo.
- Planeje uma amostra para comparar médias entre dois grupos.
- Estruture meu projeto de iniciação científica com métodos e cronograma.
